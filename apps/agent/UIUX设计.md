## 设计目标

本设计服务于浙江大学医学院附属第一医院智能问诊导诊产品的 Web 聊天页，对应 PRD 中 F1 到 F7 的功能与 LangGraph 状态流转。设计的根本任务是把"患者描述症状、Agent 多轮追问、最终推荐科室"这条对话链路，转化成可信、平静、清晰、安全的视觉与交互体验

患者来到这个产品时往往带着身体不适与对挂号的迷茫，情绪上偏焦虑，因此设计的第一目标不是炫技而是安抚与建立信任，让患者觉得自己被一个专业、克制、可靠的导诊者接住了

## 设计原则

可信赖　用衬线标题、沉稳的墨绿主色、考究的留白建立专业权威感，让患者愿意把症状放心地说出来

平静　克制用色、克制动效、充足留白、不催促的节奏，缓解焦虑而非制造紧张，急诊是唯一的强打断

清晰　严格的信息层次，追问一次只问一到两个问题，推荐结果主推与备选分明，依据可溯源，让患者一眼看懂下一步

安全　急诊警示是视觉优先级最高的元素，朱红强警示独立于主色系，不可被忽略、不可被淹没

可及　面向全年龄段尤其老年患者，大字号、高对比度、大触控区域、清晰的焦点态，无障碍优先

## 视觉调性方向

整体走 Clinical Refined 克制专业医疗路线，避开通用的医院蓝白与 AI 紫渐变。核心识别是一组沉稳的墨绿与青瓷作为主色，配衬线标题建立权威，配暖白底色与充足留白带来平静与高级感，急诊用独立的朱红强警示做唯一的高饱和打断

这个方向的取舍逻辑是：医疗问诊产品需要专业权威来建立信任（衬线标题与墨绿承担），需要平静来安抚焦虑患者（暖白与留白承担），需要唯一而强烈的急诊警示来保证安全（朱红独立承担），三者各司其职互不干扰

## 字体系统

字体是 Clinical Refined 调性的灵魂，标题用衬线建立权威、正文用无衬线保证可读，中英文配对刻意避开通用的 Inter 与 Roboto，选用有性格且专业的组合

字体族

font-display　中文思源宋体（Noto Serif SC），英文 Fraunces，用于一级标题、品牌、推荐科室名、急诊标题，衬线带来专业与权威
font-body　中文思源黑体（Noto Sans SC），英文 IBM Plex Sans，用于正文、对话气泡、说明文字，无衬线保证长文可读
font-mono　JetBrains Mono，用于依据编号、会话编号、置信度数字等技术性字符

字号阶梯（以 1rem=16px 为基准，适老化偏大）

text-display　2rem / 32px　仅欢迎页主标题与急诊大标题
text-h1　1.5rem / 24px　页面主标题、推荐结果标题
text-h2　1.25rem / 20px　小节标题、气泡内科室名
text-body　1.0625rem / 17px　正文与对话，比常规 16px 略大照顾可读性
text-aux　0.9375rem / 15px　辅助说明、依据来源、免责小字

行高　标题用 1.25，正文用 1.6，对话气泡内用 1.65 留足呼吸

字重　display 用 600，h1 用 600，h2 用 600，body 用 400，强调用 500，衬线标题用 600 的半粗获得稳定权威感而不显笨重

字距　中文标题不加字距，英文 display 用 -0.01em 微收紧获得精致感，全大写小标签用 0.08em 字距

## 间距与栅格

全部间距基于 8px 基准栅格，保证整页节奏统一，留白克制但不局促

space-1　4px　图标与文字微距
space-2　8px　标签内距、紧凑元素间距
space-3　12px　气泡内距、表单元素间距
space-4　16px　基础内距、列表项间距
space-5　24px　卡片内距、气泡间距
space-6　32px　区块间距
space-7　48px　大区块间距
space-8　64px　页面级留白

页面最大内容宽度 720px 居中，对话场景收窄到适合阅读的单列，两侧留白随屏宽弹性增长，移动端两侧内边距 space-5

## 圆角

圆角整体偏柔和以配合平静氛围，但急诊元素刻意收小圆角传达硬警示

radius-sm　6px　标签、chip、小徽标
radius-md　10px　输入框、次级卡片
radius-lg　16px　对话气泡、推荐结果卡片
radius-pill　999px　状态圆点、胶囊按钮
radius-alert　8px　急诊警示条，比常规卡片略小略硬，视觉上区别于普通信息

## 阴影与分层

克制使用阴影，主要靠边框、底色差与留白做层次，避免浮夸投影破坏平静感

shadow-sm　0 1px 2px rgba(26,26,26,0.04)　卡片轻悬浮
shadow-md　0 6px 20px rgba(31,58,46,0.08)　对话气泡与推荐卡，带一点主色色调让投影有温度
shadow-emergency　0 6px 24px rgba(214,69,69,0.18)　急诊卡片专属，带朱红色调传达紧迫
divider　1px solid color-line　常规分隔，不用阴影

## 动效

动效整体克制平静，呼应安抚焦虑的设计目标，只在关键时刻用一次精心编排的动效制造安心与确定感，不做零散炫技

时长

duration-fast　140ms　悬停、按下等即时反馈
duration-base　220ms　常规过渡、卡片展开
duration-slow　360ms　页面级、推荐结果登场

缓动　统一用 cubic-bezier(0.22, 1, 0.36, 1) 一组精致的 ease-out，退出用对称的 ease-in，禁用线性

重点时刻

页面加载　品牌与欢迎语以 staggered 方式依次淡入上浮，animation-delay 递增，建立专业开场
消息进入　用户新消息从输入区方向轻滑入，Agent 回复以打字感逐段淡入，节奏不催促
推荐登场　推荐卡片从下方上浮并伴随主色细线展开，主推先于备选出现，强调结论
急诊呈现　急诊条出现时有一次轻微的强调脉冲（缩放 1.0 到 1.02 再回弹）配合朱红，但不做持续闪烁以免刺激焦虑患者
加载等待　检索与生成期间显示克制的呼吸态指示器（青瓷色三点或细环），不用旋转菊花

无障碍　所有动效尊重 prefers-reduced-motion，该设置开启时退化为即时切换，急诊提示降级为静态高亮仍保证可见

## 图标与符号

图标采用 1.5px 描边线性风格，圆角端点，与衬线标题的精致感协调，尺寸以 20px 与 24px 为主，颜色跟随语义

科室图标　用极简几何符号区分大科系（如内科用器官轮廓、外科用十字工具感），避免写实人体插画
急诊图标　专属的实心三角感叹号，朱红填充，仅急诊场景使用
状态图标　成功用细勾、警告用琥珀感叹、信息用青瓷气泡
装饰　允许极淡的几何线条或网点作为背景纹理，不喧宾夺主

## 信息架构

产品是单页对话应用，一个聊天界面承载 PRD 中 LangGraph 状态机的全部状态，界面随对话状态切换中间消息流的内容，而非常规的多页面跳转，这样患者的注意力始终在对话本身

界面状态地图（与 PRD 状态节点一一对应）

入口态　对应接收症状，展示品牌、欢迎语、一句话说明本产品做什么、常驻免责声明入口、引导输入第一条症状

问诊态　对应澄清追问循环，Agent 气泡提出一到两个追问，可选地给出可点选的快捷选项 chip 降低输入门槛，用户气泡承载患者回答，循环往复

急诊态　对应急诊出口，强警示条置顶并占据视觉焦点，朱红底色与脉冲，明确告知立即急诊或拨打 120，常规输入区降级为弱化态，追问停止

推荐态　对应科室推荐，主推科室卡片居中突出，备选科室卡片次之，各自附依据与就医提示，底部提供"重新描述"与"结束"出口

兜底态　对应兜底，温和提示信息不足以可靠推荐，引导前往导诊台或咨询人工，重申免责，提供重新尝试入口

全局常驻

顶部品牌区　左上品牌标识与产品名，右上免责声明与关于入口
免责条　输入区上方始终保留一行免责小字，急诊与兜底态额外加强露出
高危标记　急诊态会话在顶部品牌区显示一个朱红高危徽标，提示本次会话已被标记高危

## 交互细节与微动效

焦点态　所有可交互元素聚焦时显示 2px color-accent 实线 outline 加 2px 透明间距，键盘与鼠标切换均可见，是可及性的硬要求

悬停与按下　卡片 hover 升起 shadow-sm 并边框转 color-jade，按下回弹 scale(0.99) duration-fast，按钮 hover 轻微提亮、按下下沉，反馈克制确定

错误与降级　网络异常或模型不可用时，输入区上方出现一条 color-warning 的温和提示条，Agent 回复降级为兜底话术而非报错，保持对话不中断

可溯源展开　推荐卡"查看科室原文"点击后在卡内原地展开对应 Chunk 全文，背景转 color-bg 浅区分，再次点击收起，依据可信可见

空态与边界　输入为空时发送按钮禁用且降透明度，患者发送无意义单字时 Agent 温和引导补充，不出现技术性报错

高危持续　急诊态确认后若患者继续补充，系统仍优先复评急诊，高危徽标在会话内持续显示不消失，保证安全记忆

## 适老化与可及性

字号　正文最小 17px，标题与关键信息更大，整站支持浏览器缩放与系统字号设置，不在 CSS 用固定 px 锁死缩放

对比度　所有正文与背景组合满足 WCAG AA，正文对比度不低于 4.5 比 1，大字不低于 3 比 1，朱红急诊文字在浅朱红底上用深朱红或墨色保证可读

触控目标　移动端所有可点击元素最小触控区 44 乘 44 像素，快捷选项 chip 与按钮间距充足，降低老年患者误触

颜色不唯一编码　急诊与状态信息同时使用颜色、图标、文字三重编码，色觉障碍用户不依赖颜色即可识别急诊与状态

键盘可达　全流程可用键盘操作，Tab 顺序符合阅读顺序，Enter 发送，Esc 收起展开，焦点环可见不依赖鼠标

屏幕阅读　关键元素带 aria-label，急诊警示标记为 aria-live 断言确保被朗读，气泡与卡片语义化标注

动效降级　prefers-reduced-motion 开启时所有动效退化为即时切换，急诊提示降级为静态朱红高亮仍保证醒目

## pencil 原型生成指引

在 pencil 中按以下顺序产出原型，先建变量与组件，再组合界面，最后截图验证，保证设计系统与界面一致

第一步 导入设计变量　用 set_variables 把上一节 JSON 一次性写入 .pen，作为全局设计 token，所有组件与页面都从变量取值而非硬编码

第二步 参考样式指南　用 get_guidelines 拉取 pencil 的样式 archetype 作为排版与间距的交叉参考，与本设计的 Clinical Refined 取向对齐

第三步 建立可复用组件　按核心组件清单逐个用 batch_design 建为 reusable 组件，先建原子级（QuickChip、DisclaimerBar、CitationItem），再建复合级（ChatBubble、DeptCard、EmergencyAlert），组件内一律引用变量

第四步 组合五个界面　用 batch_design 组合入口态、问诊态、急诊态、推荐结果态、兜底态五个页面，每页基于组件与栅格搭建，移动端与桌面端各一套关键页

第五步 截图验证重点　用 get_screenshot 逐页验证，重点核对三件事，急诊态的朱红警示在视觉上压倒一切常规信息、推荐结果主推与备选主次分明、正文字号与对比度满足适老化要求

第六步 布局自检　用 snapshot_layout 检查是否有元素被裁切或重叠，确保气泡与卡片在窄屏下不溢出、急诊警示条不被遮挡
